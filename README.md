# SOMPORN CLEAN V1

สร้างใหม่จากฐาน V11 ที่เสถียร และตัด Cloud ออกก่อนเพื่อให้ใช้งานภาคสนามได้ชัวร์

ฟังก์ชัน:
- เพิ่ม/เลือก อปท.
- แผนที่ดาวเทียม Esri เป็นค่าเริ่มต้น
- สลับ OSM
- ค้นหารหัสแปลงอยู่ด้านบน
- นำเข้า KML / JSON / GeoJSON
- แจ้ง “นำเข้าเรียบร้อย” พร้อมจำนวน Feature
- เพิ่ม/แก้ไข/ลบสิ่งปลูกสร้าง
- นำทาง Google Maps
- จุดสถานะสำรวจ
- Export CSV สิ่งปลูกสร้าง / สำรวจ / รวม
- Backup / Restore JSON

หมายเหตุ:
เวอร์ชันนี้ตั้งใจไม่ใส่ Cloud เพื่อกำจัดบั๊กสะสมและให้ฟังก์ชันหลักทำงานก่อน
