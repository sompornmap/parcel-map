# SOMPORN V13 Shared Realtime

รูปแบบใหม่:
- ไม่ต้องเพิ่มทีมงาน
- ใช้บัญชี Supabase กลาง 1 บัญชี
- คอมและมือถือทุกเครื่อง Login บัญชีเดียวกัน
- ทุกเครื่องใช้ GitHub Pages URL เดียวกัน
- ข้อมูลสิ่งปลูกสร้าง / จุดสำรวจ / ชั้นแผนที่อยู่ Cloud กลาง
- เปิด Supabase Realtime: เครื่องอื่นบันทึกแล้วอีกเครื่อง refresh อัตโนมัติ
- Owner เปิดคอมแล้ว Export CSV ล่าสุดได้

การใช้งาน:
1. ตั้งค่า Supabase URL + publishable/anon key ในแต่ละเครื่องครั้งแรก
2. Login ด้วยอีเมล/รหัสผ่านกลางเดียวกัน
3. เครื่องหลักส่งข้อมูลขึ้น Cloud ครั้งแรก
4. มือถือเปิดลิงก์เดียวกันและ Login
5. ข้อมูลจะโหลดจาก Cloud
6. เมื่อน้องเพิ่ม/แก้ไข/ลบ จุดใหม่จะซิงก์ และเครื่องอื่นโหลดใหม่อัตโนมัติ
7. คอม Export CSV ได้จากข้อมูลล่าสุด

สำคัญ:
- อย่าแชร์บัญชีกลางให้คนนอกทีม
- อย่าใส่ service_role key ใน HTML
- ควร Backup JSON ทุกวันเพิ่มอีกชั้น
