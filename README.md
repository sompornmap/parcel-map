# SOMPORN V16 Preconfigured Cloud

Supabase ถูกฝังไว้ในตัวโปรแกรมแล้ว
ผู้ใช้งานไม่ต้องกรอก Project URL หรือ Publishable Key

การใช้งาน:
1. อัป index.html ขึ้น GitHub Pages
2. เปิดลิงก์จากคอม
3. นำเข้าข้อมูล
4. ระบบส่งขึ้น Cloud อัตโนมัติ
5. ส่ง GitHub Pages URL เดียวกันให้น้อง
6. น้องเปิดจากมือถือและรีเฟรช
7. ข้อมูลกลางจะโหลดขึ้น
8. น้องเพิ่ม/แก้ไข/ลบ -> Cloud อัตโนมัติ
9. คอมรีเฟรช -> เห็นข้อมูลล่าสุด
10. Export CSV

คำเตือน:
- ระบบนี้ไม่มี Login
- ผู้ที่มีลิงก์สามารถอ่าน/แก้ไขข้อมูลได้
- ส่งลิงก์เฉพาะทีมงาน
